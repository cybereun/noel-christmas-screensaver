# Noël · 크리스마스 스크린세이버

깊은 겨울밤, 샴페인 골드 트리와 천천히 내리는 눈을 담은 Windows 화면 보호기입니다.

## 크리스마스 장면 5가지

1. **샴페인 골드 트리** — 깊은 밤빛과 금색 전구, 선물 상자
2. **눈 내리는 겨울 마을** — 불 켜진 목조 집과 눈 덮인 지붕
3. **오로라와 산타 썰매** — 북극의 오로라와 반짝이는 별빛
4. **별빛 속 겨울 열차** — 달빛 아래 눈 숲을 지나는 기차
5. **진저브레드 마을** — 아이싱 지붕, 사탕 지팡이, 설탕 눈

## 바로 사용하기

1. `dist/Noel.exe`를 실행합니다.
2. **크리스마스 장면**에서 5가지 중 하나를 선택하면 큰 미리보기에 바로 표시됩니다.
3. 눈의 양, 인사말, 시계, 움직임도 고를 수 있습니다.
4. **선택한 장면 Windows에 적용**을 누르면 실행 파일을 사용자 폴더에 설치하고 Windows의 화면 보호기로 지정합니다. Windows 화면 보호기 설정 창도 열립니다.
5. Windows 설정 창에서 대기 시간과 원하는 경우 재개할 때 잠금 옵션을 정합니다. 앱은 대기 시간과 잠금/암호 설정을 자동으로 바꾸지 않습니다.

전체 화면은 마우스를 움직이거나 아무 키를 누르면 종료됩니다. 실행 직후의 마우스 흔들림은 잠시 무시합니다. 창 미리보기는 Esc로 닫습니다. 음악은 재생하지 않습니다.

실행 파일을 사용자 프로필의 `%LOCALAPPDATA%\NoelScreensaver\Installed`에 설치하고 Windows 화면 보호기로 등록합니다. Windows 미리보기가 이전 실행 파일을 사용 중이면 새 버전 파일을 별도로 만들어 등록하므로 업데이트도 적용됩니다. 장면 선택은 `settings.xml`에 저장되며 Windows 목록에는 **Noel**로 표시됩니다. 원래 화면 보호기로 돌아가려면 Windows 설정에서 다른 항목 또는 `(없음)`을 선택하세요.

## 특징

- 디테일한 침엽수, 따뜻한 전구, 별과 선물, 잔잔한 눈 애니메이션
- 기본 무음, 인사말/시계 선택 표시, 눈의 양 3단계
- 24/30/60 fps 선택, 기본 30 fps
- 모니터별 전체 화면 및 Windows 설정의 작은 미리보기 지원
- 인터넷 연결, 계정, 추가 다운로드 없이 실행
- Windows 10/11 x64, .NET Framework 4.8 환경 기준

설정은 `%LOCALAPPDATA%\NoelScreensaver\settings.xml`에 저장됩니다.

## 개발 및 검증

외부 패키지 없이 Windows에 포함된 .NET Framework C# 컴파일러와 WPF를 사용합니다.

```powershell
.\build.ps1
.\dist\Noel.exe /c
.\dist\Noel.scr /s
.\dist\Noel.exe --windowed
.\dist\Noel.exe --snapshot .\docs\preview.png
.\dist\Noel.exe --snapshot-theme 1 .\docs\village.png
```

지원 명령: 인수 없음 또는 `/c` 설정, `/s` 전체 화면, `/p HWND` Windows 자식 미리보기. `/p:HWND` 형식도 지원합니다. 잘못된 미리보기 인수는 전체 화면을 띄우지 않고 종료합니다.
